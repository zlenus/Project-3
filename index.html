Limited Clinic Access Shaped Out-of-State Travel for Abortion Care in 2020

The map shows the share of each state’s residents who traveled to another state for an abortion in 2020. Use the slider to highlight states at or above a chosen percentage, and click a state to see its details.

Dataset chosen

I am using the Guttmacher Institute’s state-level abortion data, which covers all 50 states and the District of Columbia. Each column is a single measure from a single year, ranging from 2010 to 2020. I plan to focus on the measures that describe access to care and compare traveling across state lines. I want to ask whether limited local access pushes people to travel out of state for care.

Design Decisions

Given the data structure, a map visualization was the most obvious design decision for the webpage. The data is organized to focus on how each state's internal data compares to others within the nation. An alternative technique that was in contention was having an interactive bubble chart, where each bubble would represent a US state and the size of the bubble would dictate different numerical measures. This idea ultimately was scrapped because the root of the concept still relied on a map and visually might have been a bit more confusing than a standard map.

Clicking on each state and seeing its statistic was a clean interactive element to integrate into the webpage. The slide bar adds a new depth of comparison since this allows the viewer to compare the data on more of a state level; viewers can easily see where each state stands in respect to the overarching argument. Travel is shown as a percentage rather than a count, as percentage showed how severe the accessibility within each state is.

Development Process

This project from start to finish was completed by myself. The development process can be broken into 3 stages: initial exploration, map deployment, and further webpage development. It took roughly ~10 hours of work to make this page.

Initial Exploration

Typical data cleaning and exploration in Jupyter notebooks of the Guttmacher data. Graphing basic visualizations to see what elements could be used for the webpage. During this process it was clear that the webpage's argument would be displaying how abortion care is lacking in different areas; the scatterplot comparing the percentage of residents with no clinic in their county and residents that travel out of state was a great persuasive graphic to include in the final webpage.

Map Deployment

This was the most difficult aspect of the project because I have never had to create this type of rendering in D3. I had to look at a lot of example code and troubleshoot with AI code generation tools since my map wasn't rendering properly. The coloring of the borders and general map placement consumed a lot of time.

Further Webpage Development

Deployment of the comparative state measures, scatterplots, and slider bar went smoothly. Some color visualizations were continuously changed to make elements stand out depending on what interactive feature is being used. Another issue I ran into centered around the inclusion of DC on the page since it isn't a US state and its statistics were definite outliers. DC has a callout in the map due to it being a small outlier datapoint and is excluded in the overall state comparison but still included in the map as an interactive element just to show what the statistics are.
